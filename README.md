# Simple Personal Expense Tracker

A small beginner-friendly **Python** console application. It saves expenses in a local **CSV** file, with amounts in Indian rupees (INR).

## Project objective
Practice development with Git, GitHub, branches, pull requests, conflict resolution, and Markdown.

## Features
1. Add an expense (starter already works)
2. List expenses (starter already works)
3. Delete an expense (Student 1)
4. Filter expenses by category (Student 1)
5. Calculate total spending (Student 2)
6. Export expenses to CSV (Student 2)

## Requirements
Python 3.9+; no external packages.

## Run
```bash
python main.py
```
On Windows, `py main.py` may also work.
