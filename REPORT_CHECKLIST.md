# PDF Report Checklist

Submit **one** public GitHub repository URL and **one** PDF per group by 16 November 2026.

1. Cover page: project title, both names and roll numbers.
2. Repository URL, list of six features, Python + CSV technology.
3. Individual contributions and branches.
4. Screenshots of at least four meaningful commits per student, branches, pull requests, partner reviews, merge conflict and its resolution.
5. Screenshots of the working menu, add/list, filter/delete, totals and exported CSV.
6. A short conclusion.

Create the report in a word processor, insert your **real** screenshots, and export it to PDF. Do not claim incomplete features are finished.
