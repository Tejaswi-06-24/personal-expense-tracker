## Workflow
1. Clone the repository using **your own GitHub account**.
2. Each student develops on their assigned branch, not `main`.
3. Each student makes **at least four meaningful commits**. Example: implement one function, improve validation, add tests, update documentation.
4. Push branches, open **one pull request each**, review the partner's PR, and merge into `main`.
5. Demonstrate and screenshot a real merge conflict and its resolution, as described in `GIT_STEPS.md`.
6. Update this file with actual commit/PR/review details.
